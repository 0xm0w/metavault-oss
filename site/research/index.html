Five gates

Any failed gate closes the call

flowchart LR
  A["1 · MCP ask"] --> B["2 · Ceiling"]
  B --> C["3 · Warden"]
  C --> D["4 · You"]
  D --> E["5 · One call, then revoke"]
  B -.->|over ceiling| X["Denied"]
  D -.->|no daemon token| Y["401"]
1

MCP

request_capability. The schema has no secret field.

2

Ceiling

A write under a read ceiling stops here.

3

Warden

Risk and a recommended scope. It can narrow. It cannot widen.

4

Human

Approval wants x-openvault-token. The agent gets 401.

5

Injection

vaultd decrypts, calls upstream, returns the result, and the grant dies.

Five invariants

Where a secret is allowed to exist

A · At rest

AES-256-GCM

Fresh IV and tag per credential. Master key in the OS keychain. The database file is not the secret.

B · MCP

No read tool

Five tools. No get-key, no export. The agent cannot ask for what the schema does not have.

C · Prompt

Metadata only

The warden prompt is built from the request. Ciphertext and plaintext are not inputs.

D · Audit

The row is a decision

Agent, alias, scope, risk, outcome. Secret-shaped fields are dropped, including on connector failure.

E · UI

Type it once

A password field hands the value to vaultd. Later lists return alias, ceiling, and time.

Canary

27 surfaces. The string is not on them.

A synthetic secret is enrolled in test/security/canary.test.ts. The test fails if that value appears on any surface below. A separate check proves the connector itself did receive it, so the sweep is not vacant.

MCP

Enrollment, status, capability, alias list, revoke, and the deeplink.

Settings

Warden config, key save, key status, and the connection test. Status shows last4, not the key.

Renderer

Audit, aliases, credentials, pending, policies, warden settings, and IPC payloads.

Audit and the model

Audit JSON, database rows, the approve response, and the captured warden prompts.

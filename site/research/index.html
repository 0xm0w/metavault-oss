Use the key. Never see the key.

Two questions for a hackathon judge. The agent can run a scoped call. The agent, the chat, and the model cannot read the secret.

Can it use the key? Can it see the key? Warden Five gates Canary Matrix
Question 1 Brokered. Not possessed.

The agent can ask for stripe · charges.read. vaultd runs that call. The agent never receives the key.

Question 2 Not in plain text.

Not in MCP, the model prompt, the audit row, the renderer, or the database blob the agent can see. 27 surfaces, zero hits.

The warden

Metadata in. A ceiling it cannot move.

Default

llama3.2:3b

Local Ollama. About 2 GB. Prompt fields: agent, IDE, alias, scope, reason.

Also shipped

8B, 70B, or none

llama3.1:8b, llama3.3:70b, or policy only. Opt-in Meta API is the same metadata, off-device.

What changes

Judgement, not permission

A larger model is better at a write phrased as a read, slow scope-creep, and a hostile test agent. How to switch is in the docs.

A write dressed as a read

The ceiling already kills a write scope. The warden is for a read scope whose reason describes a write.

Creep across history

One request is legal. The pattern is not. The ceiling sees one request. The warden sees the trail.

A fooled model

Down, malformed, or wrong: policy and the human remain. Executed scope stays inside the alias ceiling.

The formal line, in words

The agent does not receive the secret. It sends an alias, a scope, and a reason. If policy, the warden, and a human agree, the daemon calls upstream and returns a filtered JSON result. The key stays in daemon memory for that call, then the grant is gone.

Five invariants

Where a secret is allowed to exist

A · At rest

AES-256-GCM

Fresh IV and tag per credential. Master key in the OS keychain. The database file is not the secret.

B · MCP

No read tool

Five tools. No get-key, no export. The agent cannot ask for what the schema does not have.

C · Prompt

Metadata only

The warden prompt is built from the request. Ciphertext and plaintext are not inputs.

D · Audit

The row is a decision

Agent, alias, scope, risk, outcome. Secret-shaped fields are dropped, including on connector failure.

E · UI

Type it once

A password field hands the value to vaultd. Later lists return alias, ceiling, and time.

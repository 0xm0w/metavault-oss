How it works

A dumb vault. A smart warden.

Encrypted keys and hard ceilings, then a Meta model that judges the request. The model never sees the key. Secure with the model switched off.

01Store once

One key, encrypted at rest. The master key stays in your OS keychain.

02Ask for a capability

One MCP snippet. stripe · charges.read. Never the key.

03The warden scores it

A local Meta model can narrow or escalate. It cannot widen past policy.

04You approve

One click. Writes always ask. Reads can earn standing approval.

05One call, then revoke

The daemon injects the key into that call and returns only the result.
